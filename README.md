# Freelancer Portfolio Website

Bu proje, bir freelancer/ yazılım geliştirici için hazırlanmış modern ve duyarlı bir portföy sitesidir. Ana sayfa, hakkında, projeler ve iletişim sayfalarını içeren statik bir web sitesidir.

## Özellikler

- Modern ve temiz kullanıcı arayüzü
- Responsive tasarım
- Ana sayfada geliştirme ve hizmet bilgileri
- Projeler ve iletişim sayfaları
- SCSS ile stil yönetimi
- Lightbox ve Owl Carousel gibi görsel efektler

## Teknolojiler

- HTML5
- CSS3 / SCSS
- JavaScript
- jQuery
- Lightbox2
- Owl Carousel

## Kurulum

1. Proje dizinine gidin:

   ```bash
   cd /FreelancerSite
   ```

2. Bağımlılıkları yükleyin:

   ```bash
   npm install
   ```

3. SCSS dosyalarını izlemek için aşağıdaki komutu çalıştırın:
   ```bash
   npm run scss
   ```

## Çalıştırma

Projeyi görüntülemek için aşağıdaki yolu tarayıcınızda açabilirsiniz:

```bash
public/index.html
```

Veya bir local sunucu üzerinden açabilirsiniz.

## Proje Yapısı

```text
public/          # HTML sayfaları ve statik dosyalar
scss/            # SCSS kaynak dosyaları
public/css/      # Derlenmiş CSS dosyaları
public/js/       # JavaScript dosyaları
```
